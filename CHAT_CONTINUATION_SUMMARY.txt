1. SECTION A: PROJECT AND CONVERSATION OVERVIEW
================================================================================
1.1 Project Name, Purpose, and Architectural Boundaries
- Project Name: PharmaSenseAI
- Core Purpose: An evidence-first, multi-agent pharmaceutical R&D and clinical
  operations analysis platform. It provides research scientists and clinical
  operations directors with structured queries over clinical trials, patient
  laboratory metrics, adverse event reporting, and unstructured biomedical
  literature.
- Scope Boundaries and Negative Constraints:
  * Strictly an R&D and clinical operations analysis assistant.
  * NOT a clinical decision-support tool, patient diagnosis assistant, medical advice
    provider, or emergency alerting platform.
  * Medical advice queries are blocked upfront by the Input Guardrail.
  * Synthetic dataset: 7 interconnected relational and unstructured tables (150 compounds,
    110 clinical trials, 375 trial sites, 2,000 lab results, 500 adverse events,
    250 research documents, and 400 historical interaction logs).
  * Compound similarity is attribute-based over structured metadata (target, therapeutic
    area, clinical phase); the platform contains NO chemical structures, SMILES
    strings, or molecular fingerprints.

1.2 Technical Stack & Tools
- Language & Runtime: Python 3.11 (Windows virtual environment: .venv)
- Package Management: uv (uv.lock committed)
- Primary Database: PostgreSQL 16 with pgvector extension (pgvector_engine)
- ORM & Migrations: SQLAlchemy 2.0.30, Alembic 1.13.1
- Orchestration: LangGraph 1.2+ StateGraph workflow
- LLM Providers & Models:
  * Groq (`qwen/qwen3.8-27b`) - primary candidate for Tier 1 live acceptance
  * Google Gemini (`gemini-3.5-flash-lite`, `gemini-3.8-flash`) - supported adapter
  * OpenAI (`gpt-4.1-mini`, `gpt-4o`) - reference provider
- API Framework: FastAPI (REST endpoints: /v1/analyses, /v1/reviews, /v1/evidence)
- Test Framework: pytest 8.2.0

1.3 Overall Objective and Current Stage
- Objective: Complete mentor feedback implementation (visible guardrails, genuine

   phase); never claim molecular or chemical structure similarity.
5. Out-of-scope medical advice must be refused immediately by the Input Guardrail.
